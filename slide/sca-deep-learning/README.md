# 从密钥区分器到学习型功耗分析

面向博士生同行的中文文献分享，汇报人：**向嘉豪**。前半段建立 **密钥区分器 → Oracle → 通用攻击框架 → 测量波形 → S-box 的 AVR 查表指令 → 寄存器写回与 HW/HD → 候选预测与 CPA → 分类训练与密钥评分**；后半段沿 **能否区分 → 错位后能否泛化 → 怎样选结构 → 学习哪个环节** 逐步追问。

正文以一个贯穿的字节例子、流程图和论文原图展开。每个符号在具体对象出现后引入。后半段用问题标题、四阶段导航和“得到／追问”框显示推理过程，把论文放在它所回应的具体障碍上；阅读指南补充物理假设和实验条件。Oracle 提供观测，区分器利用观测给候选密钥评分。

## 文献之间怎样承接

1. **可训练 → 可区分：**计算例子说明流程，Maghrebi 的真实排名曲线检验学习概率能否用于攻击；随后追问操作位置改变时是否仍然有效。
2. **可区分 → 可泛化：**Cagli 用共享卷积与标签保持增强回应错位，训练／验证对照解释为什么仅拟合训练集不够；随后追问卷积核、池化和层宽怎样选。
3. **可泛化 → 结构匹配：**Zaid 诊断被保留与利用的特征，再选择结构；同步 ASCAD 的参数与 GE 比较给出证据。任务匹配原则进一步引出“让网络负责哪一环”。
4. **选网络 → 选学习接口：**NLM 回到早先的 HW 预测模型，利用已知 `(z,x)` 学习泄漏预测，保留候选计算和相关性；简单回归基线检验何时需要这种复杂度。

这是一条研究问题深化的路线。前三步改进类别证据 `q_theta`，第四步回到泄漏预测 `h → g_theta`；各工作的实现、标签与预算分别呈现。

## 贯穿例子与概念顺序

- 第 6 页：`r16=p=0x00`、`r17=k*=0x01`；`eor` 得到索引，`ldi` / `mov` 设置指针，`lpm r16, Z` 把 `0x7C` 写回 `r16`，这个结果就是 `z*`。S 盒首址假设为 Flash 字节地址 `0x0200`；这是手写的未掩码 AVR 示例，非论文固件反汇编。
- 第 7–8 页：跟踪同一条 `lpm` 的写回。由此前指令可知 `r16` 的旧值为 `0x01`，写成 `0x7C` 时翻转 6 位；相对全零参考则有 5 个不同位。由此区分 `HD(r,z)` 与 `HW(z)`，再引入模型 `h`。零参考是模型假设，指令并不会先清零寄存器。
- 第 9–10 页：未知密钥时分别代入 `0x01`、`0x02`，预测同一处写回的新字节；六条合成观测展示“跨执行比较预测与测量”。相关性评分以这个数值例子引入。
- 第 11 页：已知 `p_j=0x00`、`k_j=0x01`，把实测波形与 ID 标签 124 配对；采用 HW 时，标签改为 5。
- 第 12–13 页：CNN/MLP 输出 256 类概率；真实类 124 得到 0.15，则单样本交叉熵为 `−ln(0.15)≈1.90`。若给真实类 0.80，则损失为约 0.22。
- 第 14–15 页：真实类输出分数的梯度为 `0.15−1=−0.85`，经反向传播连接到网络权重；训练完成后冻结参数，候选再按公开明文计算类别并索引概率。训练改变 `theta`，攻击比较 `k`。
- 第 19–20 页：同一个 124 对应 HW 标签 5；移动的是局部波形模式，增强仍用同一个标签计算训练损失。
- 第 26–28 页：在同一攻击框架里对照两种学习接口；先看 HW 失配现象，再沿用 124 的八个比特解释泄漏回归 `g_theta`。

## 构建

依赖：

- Python 3：常规构建脚本只使用标准库；重新裁剪原图时额外需要 PyMuPDF。
- Typst 0.14+；本次使用 **Typst 0.15.1** 构建。
- 字体：`Source Han Sans`、`New Computer Modern`、`Source Han Mono SC`。共享设置在 `style.typ`。
- 固定版本的 Typst 包：`@preview/touying:0.6.1`、`@preview/cetz:0.3.4`。首次编译会下载尚未缓存的包。

在仓库根目录运行：

```bash
python slide/sca-deep-learning/build.py
```

脚本依次编译图稿目录中的 SVG 和投影版 PDF，使用目录中现有的原图 PNG。也可以从任意目录用脚本的绝对路径运行。

生成临时视觉预览：

```bash
python slide/sca-deep-learning/build.py --preview-dir /tmp/opencode/sca-redesign/previews
```

从已保存的 IACR 原文重新生成清单中的 10 个裁剪（450 dpi，先验证 SHA-256）：

```bash
python slide/sca-deep-learning/build.py --extract-paper-figures
```

若只改了正文、未改图稿，可单独编译：

```bash
typst compile --root . slide/sca-deep-learning.typ slide/sca-deep-learning.pdf
```

## 编辑

- 修改内容：编辑 `../sca-deep-learning.typ`。
- 修改配色和字体：编辑 `style.typ`。
- 修改符号与复用公式：编辑 `notation.typ`。
- 修改出处：编辑 `sources.typ`；正文用 `#cite(...)` 固定到页底，出处字号为 10.5 pt。
- 修改图稿：编辑 `figures/*.typ` 后运行完整构建。SVG 按自然尺寸嵌入，图中文字与正文共享字号。
- 修改原图裁剪：编辑 `paper-figures/manifest.json`，再运行 `--extract-paper-figures`。原图保持作者符号，在对应页给出映射；正文与示意图统一使用 `notation.typ`。
- 编写带下标的函数时显式分组，例如 `$g_(theta)(z)$`、`$x_(i)(t)$`，确保参数括号位于正文基线。

## 数据与图形口径

论文性能数值均为**所引论文报告值**，本项目未运行网络训练复现。第 10 页是明确标注的六条合成数据；第 12–16 页的概率、损失、梯度及排名数值为说明计算过程而设定的示例。0.15 与 0.80 比较的是两种预测的损失，不代表一次真实训练更新的结果。比较论文时同时给出数据集、目标、预算或原文位置；单字节排名不代表全密钥恢复。ASCAD 原始固定密钥基准的测量通道明确标为电磁。

流程图、候选评分和失同步波形为示意；论文曲线直接从原文裁剪，保留坐标与图例，页底标注作者—年份—图号。所引用的预印本以本地下载文件为阅读版本；文件校验值见 [papers/SHA256SUMS](papers/SHA256SUMS)，具体版本差异见阅读指南。
